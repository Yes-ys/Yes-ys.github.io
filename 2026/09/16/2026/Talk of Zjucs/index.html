PFLNash

什么是纳什博弈：

  • 所有的player选择了自己的策略之后，任何一方单独改变自己的策略，都不会让自己获得更好的结果，即达到一种纳什均衡的状态。
  • 纳什博弈不是一种博弈类别，而是指一个博弈达到了纳什均衡的状态，不是所有的博弈都能达到纳什均衡的状态。

什么是Pareto最优：

  • 对于一个策略组合，如果不存在另一个可行的策略组合，使得至少一方的收益严格变好并且同时没有其他任何一方收益变差，那么原始的策略组合就是Pareto最优的。
  • Pareto最优是所有Player一起行动没有改进的空间 对比 纳什均衡是一方没有改进空间

囚徒困境，两个人坐牢，双方沉默坐牢1年，一方坦白一方沉默（坦白释放、沉默10年），双方坦白坐牢5年

  • 考虑A，若B坦白则A应该坦白（5 < 10），若B沉默则A应该坦白（0 < 1），B是一样的，所以纳什均衡就是（坦白，坦白），都坐牢5年
  • 但是Pareto最优应该是（沉默，沉默），都坐牢1年
  • 通常囚徒困境的结果是达到纳什均衡，因为坦白对于每一方来说都是严格占优策略（对于其他player的任何策略，当前选择的策略是最好的）

数据异质性

  • 数据异质性是指不同来源、不同群体、不同设备或不同时间的数据，在分布、特征、标签、噪声等方面存在显著差异，而不是来自同一个统一的数据分布。
  • 它们不是独立同分布（i.i.d.）地从同一个分布里采样出来的。

个性化性能：各个本地模型在本地测试集上的准确率的加权平均
全局性能：全局模型在各个本地模型本地测试集上准确率的加权平均

NashMM

请你给我说明一下BERT模型：

  1. BERT是基于Transformer的双向编码器表示，是一个预训练的语言模型；
  2. 使用的时候只用在后面加一个输出层，然后用少量训练样本微调就能有很好的表现（端到端的微调，不止是输出层）；
  3. BERT它使用 Transformer 的自注意力机制，让每个词在编码时同时关注整句话的所有词

关于双向编码：
BERT 的基础模块是 Transformer 编码器层。其中的多头自注意力（Multi-Head Self-Attention）是这样工作的：
输入是一个长度为 n 的序列，每个 token 都生成三个向量：查询（Query）、键（Key）、值（Value）。
对于每个 token，它的 Query 会与所有位置的 Key 计算相似度，得到一个 n×n 的注意力权重矩阵。
这个矩阵没有任何掩码限制（不像 GPT 会加一个上三角的因果掩码）。这意味着第 i 个 token 可以直接关注第 1 个、第 i-1 个、第 i+1 个以及最后一个 token。
因此，在每一层自注意力中，每个词都能看见它左边和右边的所有词——这就是“双向”的本质。
对比 GPT：GPT 使用 Transformer 解码器，在自注意力中会强制加上因果掩码（causal mask），确保位置 i 只能看到 ≤ i 的位置。所以 GPT 是单向的（自回归语言模型）。

Transfomer中注意力矩阵的计算：

  1. 对输入X乘以Wq、Wk、Wv线性变换得到Q、K、V矩阵，隐藏维度d由W确定
  2. Q、K、V都是n*d的形状，如果有H个头，每个头维度是dk = d/H即可统一表示（对应也由隐藏维度W表示），单头注意力和多头注意力本质上是通过不同的线性变化得到原始特征在不同空间下的表现，然后通过注意力机制综合这些空间下的特征（我的理解）
  3. 第i个token的query对第j个token对key的注意分数就是$q_i^T k_j/\sqrt{d_k}$，除以头维度值开方的原因是上面代表相似度的点积的均值是0，方差就是这个特征维度，当头的特征维度很大的时候数值可能非常大（分布变宽），除以该标准差之后方差变回1，防止数值爆炸
  4. 对应使用3、的矩阵表示，得到注意力分数矩阵，然后做softmax操作得到最终的注意力权重
  5. 注意力权重对应乘到Value上，然后做累加

GPT类似的自回归模型不允许看未来的token，做法就是在softmax之前对注意力分数矩阵加上因果掩码，例如对于第i个token其注意力分数是一个d维的特征向量，对于j>i的位置j其注意力分数全部变为-∞，而其他注意力分数不变

Bert则不会加这样的因果掩码矩阵，但是会加一些padding矩阵：

  1. 为了双向编码上下文以表示每个词元，BERT随机掩蔽词元并使用来自双向上下文的词元以自监督的方式预测掩蔽词元。此任务称为掩蔽语言模型。
  2. 在这个预训练任务中，将随机选择15%的词元作为预测的掩蔽词元。要预测一个掩蔽词元而不使用标签作弊，一个简单的方法是总是用一个特殊的“”替换输入序列中的词元。然而，人造特殊词元“”不会出现在微调中。
  3. 人造特殊词元“”不会出现在微调中。为了避免预训练和微调之间的这种不匹配，如果为预测而屏蔽词元（例如，在“this movie is great”中选择掩蔽和预测“great”）80%时间为特殊的““词元（例如，“this movie is great”变为“this movie is”；10%时间为随机词元（例如，“this movie is great”变为“this movie is drink”）；10%时间内为不变的标签词元（例如，“this movie is great”变为“this movie is great”）。

单模态预测怎么做：

  1. 对于有单模态标签的数据集可以直接使用单模态标签的数据集
  2. 对于没有单模态标签的数据集我们使用了单模态标签生成模块，自监督学习生成伪标签，我们用了一个现有的模块基于多模态标签和模态表征到类中心的相对距离生成标签（ULMG，问到再说）
  • 具体做法是 为每个模态 维护两个类中心 正样本类、负样本类
  • 考虑一个模态 计算一个样本到正样本类中心的距离、到负样本类中心的距离、然后针对维度做归一化
  • 然后计算相对距离 到负类中心距离-到正类中心距离除以到正类中心距离+一个微小量 就是情感正向到打分
  • 然后我们可以考虑用 单模态打分/多模态打分 乘上真实的多模态标签，得到自监督的标签

DDPG是怎么做的？

考虑四个网络，actor网络、目标actor网络，critcal网络、目标critical网络（策略网络、估值。网络）

  1. 用actor网络根据当前state给出一个action
  2. 计算目标Q值，用目标critical网络 结合当前action的及时奖励和下一个状态、以及下一个状态可能的action 给出（下一个状态可能的action由下一个状态和目标actor网络给出）
  3. 目标Q值作为标签，去更新critical网络，critical网络根据当前state和action给出预测的Q值
  4. Actor网络有一个公式计算策略梯度，用于梯度上升，基本思想是固定了Critc网络，改变Actor网络，让其给出的action朝着Critic网络能给出更高评分的方向进行
  5. 目标Actor网络和目标Crtic网络用语软更新

Q-learning

  1. 无模型采样的方式求解贝尔曼最优方程的解 Q值函数（映射表 S-A -> Q-value）
  2. 核心是利用时序差分迭代更新 令下一时刻Q值的估计 为当前时刻估计+学习率*时序差分
  3. 时序差分 当前Action的实际Reward + gamma*下一时刻的最大Q值（根据下一时刻的状态，和当前时刻Q表去挑选令Q值最大的Action）-当前时刻的Q值
  4. 探索是以一定的概率不选择下一时刻最大的Q值，而是随机选择Action
  5. 为什么需要探索而不全贪心，避免局部最优，一个简单的赌博机，动作A+1，动作B+100，有且仅有一个状态，若随机到Q(A,S) = 1，Q(B,S) = -100，全贪心最终只会收敛到选A，因为缺乏对动作真实的执行，不清楚其实际奖励，可能导致永远无法发现更好的路径。
